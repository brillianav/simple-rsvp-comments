# Simple RSVP Comments

Simple RSVP Comments adalah project awal untuk membuat fitur RSVP sederhana dengan kolom komentar. Repo ini masih berada pada tahap inisialisasi, sehingga struktur aplikasi, framework, dan detail implementasi dapat disesuaikan dengan kebutuhan berikutnya.

## Tujuan

- Menyediakan halaman RSVP yang mudah digunakan.
- Mengumpulkan nama, status kehadiran, jumlah tamu, dan komentar.
- Menjadi dasar pengembangan fitur undangan, event, atau guestbook sederhana.

## Status Project

Saat ini repo baru berisi dokumentasi awal. Belum ada source code aplikasi, dependency, atau konfigurasi runtime.

## Rencana Fitur

- Form RSVP dengan validasi input.
- Daftar komentar dari tamu.
- Penyimpanan data RSVP.
- Tampilan responsif untuk desktop dan mobile.
- Opsi admin sederhana untuk melihat respons yang masuk.
